Syntax guide (everything this calculator understands)
  • Piecewise: { x^2 if x<1; 2 if 1<=x<2; 4-x otherwise } (separate pieces with ;) — or use the Piecewise tab to build it with boxes. Also works as x<1 ? x : 2.
  • Chained inequalities: 0 < x <= 1; intervals: x ∈ [0, 1); combine with and, or, xor, not (or ∧ ∨ ¬).
  • Summation / product: ∑(k^2, k, 1, 5) = Sum(…), ∏(1+x/k, k, 1, 4) = Prod(…). The index can be any letter.
  • Calculus: ∫(t^2, t, 0, x) definite integral, D(sin(t^2), t, x) derivative at x, D2(…) second derivative, Lim(sin(t)/t, t, 0) two-sided limit.
  • Functions: trig, inverse trig, hyperbolic, inverse hyperbolic, exp, ln, log (base 10) and log(x, base), sqrt, cbrt, nthRoot, floor, ceil, round, abs, sign, mod, gcd, lcm, factorial n!, gamma, beta, erf, erfc, combinations, permutations, mean, median, min, max, std, variance, plus step helpers H, rect, tri, sinc, clamp, frac.
  • Symbols: × ÷ · − π √ ∛ ≤ ≥ ≠ ∞ ° ⌊x⌋ ⌈x⌉ |x| x² x³ x⁻¹ a₁ and all Greek letters.
  • Any letter other than the variable is a parameter: define it in the Constants box (k=2). Use * or a space between variables: k x, not kx.
